**Goal:** Ship the first tagged release, v0.1.0, from a commit that passes CI. It uses one package manager, working lint, type-check, test and build scripts, and accurate setup docs.

**Scope:** The six "Release Foundation" checklist items. Out of scope: application features; new security controls such as Dependabot, SECURITY.md, CodeQL and npm audit. Those are deferred to v0.2.0 under Follow-ups.

**Sources:** the checklist; repo state on `akkaraponph/clam` @ f7d5039 (2026-11-21).
