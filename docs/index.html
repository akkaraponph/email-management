Email template editor example

Make the message yours.

Edit email content, work with template variables, preview your changes and export HTML from one workspace.

Get started

Edit visually

Write and format email content in a TipTap-based editor.

Preview with data

Use variables and sample values to inspect a template.

Export content

Choose from HTML and variable data export options.

Run the example

Install a Node.js version supported by the project's Next.js version, then run:

npm ci
npm run dev

Open localhost:3000. Demo templates are stored in your browser. See the README for database and API setup.
